# Дуэли

`POST /api/duels` принимает `mode: random|invite`. Для приглашения нужен `opponentHandle`;
`problemId` выбирает конкретную опубликованную задачу с отправкой кода. Без него задача случайная.
При случайном сопернике конкретная задача не задается. Фильтра тем в дуэлях нет.
Подсказки ников используют обычный `GET /api/users?q=...`.
`GET /api/duels/problems` отдает доступные задачи без черновиков и угадывания, в том числе для их авторов.

Состояния запроса: `queued`, `invited`, `matched`, `declined`, `cancelled`, `expired`.
`GET /api/duels/current` возвращает последний свой ожидающий запрос, иначе 204.
`GET /api/duels/{id}` доступен только участникам запроса. `POST /api/duels/{id}/accept`,
`/decline`, `/cancel` принимают, отклоняют и отменяют приглашения или поиск.

## Список и параллельные дуэли

`GET /api/duels?phase=active&offset=0&limit=20` возвращает свои комнаты, исходящие запросы
и входящие приглашения. Фазы: `active`, `finished`, `all`. Ответ: `items` и `total`.
Две записи случайного подбора объединяются в одну комнату до применения пагинации.
`problemId`, `problemTitle`, `difficulty`, `startAt` и `surrenderedUserId` описывают задачу
и состояние комнаты; `expiresAt` содержит срок ожидания или фактический конец дуэли.

Можно играть несколько дуэлей одновременно, отправлять приглашения и искать нового соперника.
Ожидание одной дуэли не блокирует остальные. Одновременно существует один свой случайный поиск;
его повторное создание возвращает тот же запрос. Принятие приглашения не отменяет другие дуэли.
Список обычных соревнований `GET /api/contests` дуэли не содержит.

## Задача и время

Случайный поиск подбирает двух разных ожидающих пользователей и случайную задачу.
Конкретная задача закрепляется за приглашением при его создании; случайная - при начале комнаты.
Оба участника решают одну неизменяемую версию. Длительность определяется сложностью:

- `easy`: 1 час.
- `medium`: 2 часа.
- `hard`: 3 часа.

Комната начинается после подбора или принятия приглашения; оба участника регистрируются автоматически.
Начало возможно только при доступном согласованном исполнителе. Отпечаток среды сохраняется
с комнатой, чтобы смена оборудования не смешала результаты. Сводки лучшего результата
используют ту же среду. Если она недоступна, новые посылки комнаты
получают 503; история и исходный замер остаются привязаны к прежнему оборудованию. Ожидающие поиски
повторно сопоставляются после восстановления исполнителя. Поиск истекает через 15 минут,
приглашение - через 24 часа. Начавшиеся комнаты через редактор контеста не изменяются.

## Результат и сдача

Сравнивается минимальное итоговое время корректного решения общей задачи. Учитываются посылки
этой комнаты, закрепленной версии и среды, отправленные от начала включительно до конца
исключительно. Более ранняя отправка не дает преимущества. Принятое решение выше отсутствующего;
равные времена делят место. Проверка отправленной вовремя посылки может завершиться после таймера.
В этот период `Contest.resultsPending` сохраняет обновление доски; окончательный победитель
показывается после проверок в пределах срока ожидания рейтинга.

`POST /api/contests/{id}/surrender` доступен участнику идущей дуэли. Сдача сразу завершает ее
поражением этого участника, даже если до этого у него было лучшее время. Соперник выигрывает
и без принятого решения. Повтор своей сдачи не меняет результат; чужую сдачу перезаписать нельзя.
После завершения новые посылки в комнату не принимаются, остальные дуэли продолжаются.
Сдача считается участием для рейтинга обоих игроков; результата незавершенных проверок ждать не нужно.

Подбор, принятие и сдача сериализуются общей блокировкой PostgreSQL. Создание комнаты,
две регистрации и уведомления фиксируются одной транзакцией.

## Уведомления

`GET /api/notifications?offset=0&limit=20` возвращает свои уведомления, общее число и счетчик
непрочитанных. `PUT /api/notifications/{id}/read` отмечает свое уведомление прочитанным.
Типы: `duel_invitation`, `duel_started`, `duel_declined`, `duel_cancelled`, `duel_surrendered`.
Текущий `duelStatus` скрывает действия у отмененного или истекшего приглашения.
Письма и сообщения во внешние сервисы не отправляются.
