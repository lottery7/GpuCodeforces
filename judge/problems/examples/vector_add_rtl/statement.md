# Сложение векторов (RTL)

Даны массивы `A` и `B` из `N` целых 32-битных чисел. Запишите в `C` их поэлементную сумму:
`C[i] = A[i] + B[i]` с переполнением по модулю 2³².

Схема — модуль `solve` на SystemVerilog. Массивы — память судьи: адрес на `A_addr`, данные на `A_data`
на следующем такте; запись в `C` — `C_addr`, `C_data`, `C_write`. По `start` схема начинает работу и
поднимает `done`, когда всё записано. Score — такты до `done` × глубина логики (ячеек на самом длинном пути
между регистрами) × транзисторы схемы после синтеза: меньше — лучше. Схема должна быть синхронной, без защёлок и
асинхронных сбросов.
