Даны матрицы `A` размера `M×K` и `B` размера `K×N` из чисел `float`, записанные по строкам.
Запишите в `C` их произведение размера `M×N`.

```cpp
void solve(const float* A, const float* B, float* C, int M, int N, int K);
```

Все три массива лежат **в памяти CPU**: копирование на GPU и обратно входит в измеряемое время.
Тензорные ядра (`HMMA`) запрещены.

## Пример

`M = 2, N = 2, K = 3`, `A = [[1, 2, 3], [4, 5, 6]]`, `B = [[1, 0], [0, 1], [1, 1]]`,
ответ `C = [[4, 5], [10, 11]]`.

## Ограничения

- 1 ≤ M, N, K ≤ 2048;
- допуск сравнения `1e-3`.
