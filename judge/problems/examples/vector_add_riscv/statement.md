# Сложение векторов (RISC-V RVV)

Даны массивы `A` и `B` из `N` целых 32-битных чисел. Запишите в `C` их поэлементную сумму:
`C[i] = A[i] + B[i]` с переполнением по модулю 2³².

Решение — функция `void solve(const int32_t* A, const int32_t* B, int32_t* C, int32_t N)` на C, C++ или ассемблере
RISC-V (RV64GCV, VLEN = 256). Score — инструкции плюс 10 за каждый промах L1 и 100 за каждый промах L2 сверх того,
что тратит обвязка судьи с пустой `solve`: меньше — лучше.
