# Сложение векторов (Coral NPU)

Даны массивы `A` и `B` из `N` целых 32-битных чисел (`N` ≤ 2000). Запишите в `C` их поэлементную сумму:
`C[i] = A[i] + B[i]` с переполнением по модулю 2³².

Решение — функция `void solve(const int32_t* A, const int32_t* B, int32_t* C, int32_t N)` на C или C++ для ядра
Coral NPU (RV32IMF, Zbb, векторное расширение Zve32x с VLEN = 128). У ядра 8 КБ памяти кода и 32 КБ памяти данных, в
которой лежат и массивы теста. Score — число инструкций, которые ядро выполнило до остановки: меньше — лучше.
